Coolify では、アプリやデータベースなどのリソースを **プロジェクト** と **環境** で整理します。  
インストール直後に作られる **My First Project** の意味を押さえておくと、WordPress など後続の手順が分かりやすくなります。

## なぜ分かれているか

VPS 上には複数のアプリ（ブログ、写真バックアップ、ファイル共有など）を載せられます。  
プロジェクトと環境は、それらを **論理的な入れ物** としてまとめ、管理画面上で探しやすく・設定しやすくするための仕組みです。サーバーの物理構成そのものとは別の概念です。

## プロジェクト（Project）

**プロジェクト** は、関連するリソースを束ねる単位です。

- 例: WordPress サービスと、それに付随する MariaDB
- 後から Immich や Nextcloud などを同じプロジェクトに追加してもよいし、用途ごとに別プロジェクトに分けてもよい

初期セットアップで作成する **My First Project** も、このプロジェクトのひとつです。

## 環境（Environment）

**環境** は、プロジェクト内の実行コンテキストです。初期状態では **production** が用意されます。

開発用と本番用を分けたいときに環境を増やしますが、このガイドでは **production のまま** 進めて問題ありません。

## このガイドでの進め方

1. インストールウィザードで **My First Project** を作成する（[[guides/coolify/installation|インストール手順]]）
2. そのプロジェクト（production 環境）に、WordPress などのリソースを追加していく

用途ごとにプロジェクトを分けるのは任意です。まずは My First Project に追加し、必要になってから整理すれば十分です。
