# WordPress ガイド用スクリーンショット

`guides/wordpress/installation.md` で参照する画像をここに配置します。

想定ファイル名:

- `project_create.png` — WordPress 用プロジェクトの作成
- `service_add.png` — サービス一覧で WordPress を選択
- `domain.png` — ドメイン設定
- `deploy.png` — デプロイ完了
- `wp_language.png` — WordPress 言語選択
- `wp_setup.png` — サイト情報入力

配置後、ガイド本文の HTML コメントを外して画像を有効化してください。
